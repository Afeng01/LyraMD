AI 精灵 Prompt

这些模板会用于后续选中文本后的 AI 操作。使用 {{selection}} 表示当前选区。选中文本后按 Cmd/Ctrl+J 打开 AI 精灵，先预览结果再决定替换、插入或复制。

AI 精灵怎么用
  1. OpenAI 官方账号：Base URL 保持 https://api.openai.com/v1，填入 API Key 和模型名。
  2. cpa/new-api：把 Base URL 换成你的网关地址，Model 填网关里可用的模型。
  3. 在正文里选中文本后按 Cmd/Ctrl+J 打开 AI 精灵，选择模板或输入指令，预览结果后再替换、插入或复制。

Codex MCP 如何使用
  1. 在这里安装后，保持 LyraMD 打开当前文档。
  2. 在 Codex 里请求它使用 LyraMD MCP 读取或写入当前文档。
  3. LyraMD 负责安装配置和运行本地 bridge；Codex 负责真正调用 MCP 工具。

LyraMD 使用指南

这里是当前集成的实际使用方式，避免把 MCP、终端和草稿逻辑混在一起。

  1. 在 LyraMD 中写笔记，保持当前文档打开；未保存的新内容会先进入草稿。
  2. 需要正式落盘时，用保存或工作目录里的新建按钮，把文件放进对应文件夹。
  3. 终端里和 Alice 或 Codex 讨论内容时，让它通过已配置的本地连接读取当前文档，或直接把文件路径发给它。
