# UI 设计沉淀：ColaMD 设置界面“脱脂”规范

## 背景
基于“如非必要，勿增实体”的第一性原理，对设置界面进行了极致简化重塑。

## 核心准则

### 1. 物理稳定性 (Physical Stability)
- **固定尺寸**：设置对话框固定为 `720px * 500px`。禁止 Pane 切换时窗口高度随内容变化，避免视觉跳跃感。
- **静态框架**：只有右侧内容区（Content Pane）在切换时淡入淡出，外层容器和导航保持静态。

### 2. 极致侧边栏 (Minimalist Sidebar)
- **纯净索引**：仅保留“线型图标 + 标题”。移除所有二级描述、脚注说明。
- **紧凑间距**：侧边栏宽度控制在 `200px` 左右，压缩按钮高度。

### 3. 视觉呼吸感 (Visual Immersion)
- **磨砂玻璃**：使用 `backdrop-filter: blur(32px)`。
- **高透明度**：背景使用 `color-mix(in srgb, var(--bg-color) 15%, transparent 85%)`，确保用户在设置时能感知写作背景。
- **隐形分区**：取消显性的卡片背景色，通过增大行间距和外边距来实现逻辑分层。

### 4. 交互式快捷键 (Interactive Shortcuts)
- **按键块样式**：快捷键表现为可点击的交互块。
- **状态反馈**：点击后进入“录制中...”闪烁状态，按 `Esc` 退出。

### 5. 信息密度 (Information Density)
- **微字号**：右侧正文字号微缩至 `12.5px`，元信息缩至 `11.5px`。
- **专业感**：优先使用 `color-mix` 进行边框处理，确保在不同主题下视觉的一致性和通透感。
