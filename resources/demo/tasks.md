# 待办列表

LyraMD 支持**可点选的待办列表**。下面这些 checkbox 是真的能点的：

- [ ] 点击这个 checkbox 试试
- [x] 这个已完成，再点一下就取消勾选
- [ ] 把光标放在这行上，按 **⌘+Enter**（Windows 为 Ctrl+Enter）也能切换
- [ ] 待办支持嵌套：
  - [ ] 子任务也能单独勾选
  - [x] 写法就是多两个空格缩进

## 说明

- 勾选状态即时反映在编辑器里，源码中 `- [ ]` 与 `- [x]` 随之更新
- 在普通窗口里按 **⌘S** 会把勾选状态写回文件
- 文件保存后，外部程序（比如你的 Agent）修改它时，编辑器会实时同步进来——详见「帮助 > 新功能演示 > Agent 同步」

## 配一个计划模板

- [ ] 明确目标：一句话说清要产出什么
- [ ] 列出步骤：每步一个 checkbox
- [ ] 交给 Agent 跑第一步
- [ ] 验收：在 LyraMD 里直接读结果
