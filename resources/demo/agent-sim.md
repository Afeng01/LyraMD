# Agent 同步

LyraMD 是 agent-native 编辑器：**外部程序修改已保存的 `.md` 文件时，窗口实时跟进**。Agent 写它的，你看你的，同一份文件。

## 怎么体验

1. 把任意文档（或本页内容）保存成一个自己的 `.md` 文件（⌘S）
2. 保持它在 LyraMD 中打开
3. 在终端里追加一行（换成你保存的真实路径）：

```bash
echo "- Agent 刚写入的一行：$(date)" >> /path/to/your-note.md
```

窗口里的内容会**自动出现**这一行，并弹出外部变更摘要（增删了哪些行一目了然）。

再试试 Agent 常用的原子保存（临时文件 + rename 整体覆盖）：

```bash
printf '# 重写\n\nAgent 用 rename 覆盖了整个文件\n' > /tmp/rewrite.md
mv /tmp/rewrite.md /path/to/your-note.md
```

## 破坏性覆盖拦截

如果外部更新试图**清空文稿**或**一次性删掉大量内容**，LyraMD 会拦截这次覆盖，提示「已阻止覆盖」，并把覆盖前的内容保留为本地恢复副本——恢复时会写成新草稿，绝不悄悄吞掉你的文字。

- 正常的外部改动：实时进入编辑器，无需手动刷新
- 你的编辑：需要 **⌘S** 才写回文件
- 高风险改动：先拦截、给摘要、留后路

## 为什么这样设计

Agent 的产出应该直接落盘成 Markdown，而不是贴进聊天框再人工搬运。LyraMD 把文件当作唯一事实源：Agent 改文件 = 更新文档；同时用风险闸门兜底，防止一次失控的写入毁掉整篇文稿。
