# LyraMD 1.3.8 发版证据包

此文件帮助发布者复核 1.3.8 是否把 2026-07-09 文稿安全事故后的修补，以可安装、可理解的形式交付给用户。

## 发布范围

- 版本：`1.3.8`
- 基线：`v1.3.7`
- 主要用户变化：高风险外部更新不再直接覆盖编辑器；覆盖前正文会被保存为本地恢复点；恢复永远写成新草稿。
- 同步说明：应用内更新日志、中文/英文 README 的下载版本和安全协作步骤。

## 行为边界

- 保护触发条件：外部更新把非空文稿变空、正文缩减达到高风险阈值，或移除/改写大量行。
- 不承诺：这不是对所有恶意、异常或逻辑错误写入的绝对防丢失保证；用户仍应在关键文稿上保留自己的文件备份。
- 旧运行实例：磁盘上的 `.app` 更新后，必须退出并重新打开，才能运行新逻辑。

## 发布验收

发布前执行并记录：依赖一致性、完整测试、生产构建、macOS/Windows distributables、DMG 校验、安装包冷启动 smoke、GitHub Release 资产核对。

人工重点复看：

1. 制造一次“非空文稿 -> 空内容”的外部文件写入，确认正文不被覆盖且出现恢复入口。
2. 从 macOS DMG 安装后确认菜单、设置中的 `1.3.8` 更新日志和图片渲染正常。
