# 格式速览

这一页集中演示 LyraMD 的常用行内与块级格式，全部按真实渲染展示。

## 高亮

用双等号把文字包起来就是**高亮**：==这段文字被高亮了==，适合标记重点和待确认内容。

源码写法：`==高亮内容==`

## 代码块复制

悬停在代码块上会出现「复制」按钮，一键复制整段代码：

```ts
function greet(name: string): string {
  return `你好，${name}！`
}

console.log(greet('LyraMD'))
```

试试点击右上角的「复制」，然后粘贴到任何地方。

## 行内格式全家福

**加粗**、*斜体*、~~删除线~~、==高亮==、`行内代码`，以及 [链接](https://github.com/Afeng01/LyraMD)（Cmd/⌘+点击在浏览器打开）。
