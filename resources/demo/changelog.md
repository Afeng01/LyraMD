# 新功能总览

欢迎来到 LyraMD 的**可玩演示**。这一组页面按 LyraMD 的真实功能编写，随便点、随便玩——演示窗口是内存副本，关掉即走，不会写坏任何文件。

从「帮助 > 新功能演示」可以随时回到这里。

---

## 这套演示有什么

- **待办列表**：可点 checkbox，光标放待办行按 **⌘+Enter**（Windows 为 Ctrl+Enter）也能切换 → 见「帮助 > 新功能演示 > 待办列表」
- **格式速览**：`==高亮==`、代码块一键复制、表格与引用的真实渲染效果 → 见「格式速览」
- **Agent 同步**：外部程序修改已保存的 `.md` 文件时，编辑器实时跟进；破坏性覆盖会被拦截并保留恢复草稿 → 见「Agent 同步」

## 最近版本亮点

- **导出 Word**：文件菜单「导出 Word…」把当前文档存为 `.docx`，保留标题、列表、表格、链接、代码块和本地图片；保存对话框默认锚定在原文档旁边
- **主题系统**：主题菜单内置多套浅色/深色主题，语义色经过对比度自动检查，自定义主题也不容易出现不可读文字
- **非模态更新提示**：有新版本时标题栏出现轻量横幅，不打断输入；每个版本的更新说明只弹一次
- **VS Code 扩展**：仓库 `vscode-extension/` 目录提供「在 LyraMD 中打开当前 Markdown」命令，未保存内容会先落盘再交给 LyraMD

## 想深入玩？

把任意一份演示内容复制进你自己的文档并保存（⌘S），它就变成一个被文件监视器守护的普通 Markdown 文件——Agent 改一行，窗口跟着动。
