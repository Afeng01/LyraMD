# 人话版：你的编辑器要不要跟橘子的新版

一句话背景：你天天写的这个 Markdown 编辑器（LyraMD），是你从他做的 ColaMD 抄过来改的私房版。他这几个月更新了 77 笔，这份清单就是说：**哪些值得抄回来、哪些你比他强、哪些是你家该扫的垃圾、哪些是你当年就有道理没跟的。**

## 先说结论

1. **四个立等可享的小舒服**：关拼写红波浪线、PDF 导出没白边且跟主题变色、保存窗口记住你当前文件夹、代码块一键复制。都便宜，第一批就做。
2. **两个中型实用**：导出 Word（发给不玩 Markdown 的人）、待办清单可以直接点勾。第二批。
3. **一个想做但别心疼**：长文自动切图发微信。他做这功能翻车了 6 次，值得单独试一次，砸了就放弃。
4. **最要紧的一条警告**：那 14 样"你比他强"的功能（B 表）意味着——**永远别直接装他的新版覆盖你的**，想同步只能按清单一样一样搬。
5. 你家有 6 块旧垃圾（C 表），不扫的话以后每加功能都多踩雷。

## A 表：他做了、你还没有、值得抄

| 项 | 改完你会感觉到什么 | 贵不贵 |
|---|---|---|
| A1 导出 Word | 写完的文章能直接发 Word 给任何人看，格式不乱 | 中 |
| A2 长文切图 | 长笔记一键变成几张图片，直接甩微信群/小红书 | 贵，翻车预备 |
| A3 PDF 白边 | 导出的 PDF 跟着你的深色/浅色主题走，不再镶一圈丑白边 | 便宜 |
| A4 记住文件夹 | "保存"弹窗不再每次跳回老地方，就在你当前文件夹 | 便宜 |
| A5 复制代码 | 看到文章里的代码块，鼠标一点就复制走，不用拖选 | 便宜 |
| A6 更新横幅 | 新版本悄悄告诉你"有更新了"，不再弹窗打断你打字 | 中 |
| A7 主题换着玩 | 主题变成"一个文件就是一个主题"，可以自己导入着玩，还有防呆检查防止主题文字看不清 | 便宜偏中 |
| A8 流程图 | 笔记里能画 Mermaid 流程图/架构图 | 中，按需 |
| A9 数学公式 | 能插公式，点一下就能改 | 中，按需 |

| A11 拼写红线 | 英文单词底下那些冤枉你的红色波浪线，全部消失 | **最便宜，两行** |

| A13 演示文档 | 装好就有一份能玩的功能样例（他新版带的） | 便宜 |

## B 表：你比他强的 14 样（不用干活，是护身符）

这 14 样没有任何动作要做，它们的唯一用途是：**哪天你想"跟上游同步"的时候，知道什么会被覆盖掉。**列在这里防止将来误判：

AI 改你的文件前先看摘要、改坏一键回退 · 破坏性覆盖会被强制拦下 · 崩了不丢稿（快照+恢复面板）· 多窗口并行写 · 左侧工作区文件树带置顶和废纸篓 · 草稿自动存 · 内置 AI 助手面板 · 你自己的搜索（带记忆）· 中文排版+frontmatter 支持 · 快捷键持久化 · 图片资产管理 · Windows 发版线+设置窗 · 57 项自动体检。

**这 14 条 = 你的护城河，上游一条都没有。**

## C 表：你家该扫的 6 块垃圾

| 项 | 大白话 | 不扫的代价 |
|---|---|---|
| C1 | 同一份主题样式存在两个地方，其中一处是死的没人用 | 改样式时不知道改哪份，白改 |
| C2 | 一个样式文件里有一整行塞了七千多个字符 | 每次改动 diff 糊成一团，跟新版合并必打架 |
| C3 | 好几处样式定义重复了三遍，互相覆盖 | 看着像 bug 其实不是，查半天 |
| C4 | 导出网页版忘了带样式，导出来的全是裸文 | 导出功能等于残了 |
| C5 | 代码甚至**产品界面**里还写着"ColaMD"的旧名字和旧故事 | 你自己用着别扭，截图分享出去更别扭 |
| C6 | 程序一启动就把 52 个模块全加载，包括根本没用到的 | 启动变慢，跟 A1 一起修最省 |

## D 表：你当年故意不跟的 7 样——复核结果：你全对
